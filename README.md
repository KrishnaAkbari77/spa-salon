# FashionCart 🛍️

A multi-page e-commerce fashion store built with pure HTML and CSS. Covers the complete shopping flow — from browsing products to checkout — across separate category pages for Men, Women, and Kids.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Homepage with featured products |
| `men.html` | Men's clothing category |
| `women.html` | Women's clothing category |
| `kids.html` | Kids' clothing category |
| `product-detail.html` | Individual product view |
| `cart.html` | Shopping cart |
| `wishlist.html` | Saved/wishlist items |
| `checkout.html` | Checkout form |
| `login.html` | User login |
| `register.html` | User registration |
| `user-profile.html` | User profile page |
| `contact-us.html` | Contact page |

## Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — custom styling and layout
- **Font Awesome** (webfonts) — icons throughout the UI

## Getting Started

No installation or build step needed.

```bash
git clone https://github.com/KrishnaAkbari77/fashionCart.git
cd fashionCart
# Open index.html in your browser
```

Or just open `index.html` directly in any browser.
